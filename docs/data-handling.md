# 数据处理说明

本文描述开源版本的已知数据流，供部署者和用户评估；它不是替代适用法律要求的隐私政策。运营公开服务前，运营者应根据其所在地、数据保留策略和第三方服务补充正式隐私政策与联系渠道。

## 本地客户端

- Mac Host 保存本地会话、工作区配置和运行日志；Relay 设备凭证优先保存在 macOS 钥匙串。
- iOS 将 Relay 与 DeepSeek API key 保存在 iOS Keychain；本地会话缓存存储在设备上。
- iOS 仅在用户开启语音输入时请求麦克风和语音识别权限。

## Relay 服务

Relay 会保存账号标识、已授权设备、会话/授权状态及其哈希化访问令牌。为了在账号删除时撤销 Sign in with Apple 授权，Apple refresh token 使用由服务端 secret 派生的 AES-256-GCM 密钥加密保存，不会返回客户端或写入日志。Relay 通过加密连接转发 iPhone 与所属 Mac 之间的请求和 WebSocket 数据。用户可以在 iOS App 或网站授权控制台永久删除账号；删除会移除 Relay 中的账号、登录身份、设备、会话、授权记录和访问凭证，并立即撤销关联设备连接。Mac 上的本地项目文件和第三方服务账号不在删除范围内。自托管部署者仍应设置数据库访问权限、备份保留期和日志策略，并在正式隐私政策中说明备份与日志中的实际删除时限。

## 可选第三方服务

启用“DeepSeek 语音润色”后，iOS 会将语音识别后的文本和用户提供的 DeepSeek API key 发送至 DeepSeek API 处理；该功能默认不因安装而启用。使用前请审阅对应第三方的服务条款和隐私政策，且不要在语音内容中包含不应交由第三方处理的敏感信息。
